## 团队基建

**[进入团队基建专区](https://github.com/orgs/lec-org/repositories?q=topic%3Alec-infra)**

团队长期维护的公共服务、应用、共享资源和开发设施，按用途集中查找。登录后会显示你有权访问的私有仓库；组织成员也可在首页切换到 Member 视图查看完整分类目录。
